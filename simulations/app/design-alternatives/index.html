Four directions for the results viewer

Static mockups, not the running app. Each shows the same view of the same study — study 05, root mean squared error against the risk ratio — so the four can be compared on layout and register rather than on content.

Every number here is real

All figures are computed from data/aggregated/05_rr_to_or_nrep1000.csv for the view the app opens by default: target = population parameter, br = 0.01, br_guess = 0.01, p_exp = 0.50, 15 conditions, 1,000 replications each. The figure is rendered from that same slice by make-figure.R. Nothing was invented to fill a layout, so the copy can be checked.

What changed, beyond the styling

Reviewing the numbers to write these mockups turned up two things the current design does not say, and all four directions now say them:

  • The default view switches the study off. The held-constant defaults put br_guess equal to br, so the assumed baseline risk is exactly correct and no misspecification is being exercised — which is the entire subject of study 05. It also lands on br = 0.01, the smallest value in the grid, where the whole 2×2 table holds under one expected case at n = 50 and the continuity correction applies to almost every replication.
  • Coverage near 1.00 is not good news. Every route reports a standard error close to twice the empirical one, so the intervals are too wide rather than well calibrated. Presenting coverage as a headline number without the SE ratio beside it inverts the finding — an argument for putting all measures in one table rather than promoting one of them into a card.

Every caveat that the current design buries in a grey paragraph moves to a right-hand margin column, where the reader can take it or leave it. Sentences carry a small reference mark to the note that qualifies them.

What all four refuse to do

The current design reads as a product dashboard because of a specific set of devices. None of the four uses any of them.

DroppedInstead
Hero metric cards — one big number per box Numbers live in a table, or in a sentence that says what they are the mean of. A single promoted number cannot carry its own scope.
Uppercase letterspaced micro-labels Sentence-case labels, or ordinary table headers. Small caps are a typographic device, not a way to make a label look important.
Rounded cards, drop shadows, panels on a tinted page Hairline rules and white space. Three rules make a table; a box adds nothing a rule does not.
Pill badges for status — RESOLVABLE A sentence saying what can and cannot be concluded, and why. A badge compresses a statistical caveat into a word.
Competitive language — leads on this measure Ordering, stated as ordering: smallest mean RMSE, with the measure and the set it is averaged over named.
Paragraphs of explanation on the page One line per finding, with the reasoning on a hover circle, and measure definitions on the column headers. The page carries conclusions; the reader asks for the derivation.
Accent colour as decoration Colour encodes data. The five method colours mean one route each; rose marks only the current selection.
Boxed grey facet strips and a separate plot legend Panel labels set as captions; the table is the legend, so the mapping from colour to route is written once.
